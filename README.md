# ConnectHub – Social Media Platform

## About the Project
ConnectHub is a simple social media web application developed as part of my Full Stack Development internship at CodeAlpha.

## Features
- User registration and login
- Password hashing using bcryptjs
- Create and view posts
- Like and unlike posts
- Add and view comments
- User profile and bio management
- SQLite database for storing information
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- bcryptjs

## How to Run the Project
1. Install Node.js.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run `npm install`.
5. Run `npm start`.
6. Open `http://localhost:3000` in your browser.
